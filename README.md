# code-switching-codesaviours-si26-humna

Dataset collection project for Code Switching NLP (Roman Urdu + English), 
Code Saviours SI-26.

## Project Overview
This project collects and labels naturally occurring code-switched sentences 
(Roman Urdu mixed with English) as spoken by Pakistani social media users. 
Each word in every sentence is labeled as URD (Roman Urdu), ENG (English), 
or MIX.
